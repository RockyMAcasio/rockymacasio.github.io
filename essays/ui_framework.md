# The Fun and Challenges of UI Frameworks

When I first started learning HTML and CSS, I thought building websites was pretty simple. However, after working on different assignments in ICS 314, I realized how much effort goes into making a website look good. Learning Bootstrap 5 introduced me to a new way of designing websites. Although it was challenging at first, I found it unique and fun because of how many different things you can create with it.

One of the biggest benefits of Bootstrap 5 is how much easier it makes designing websites. Instead of writing a bunch of CSS from scratch, Bootstrap provides classes that help with layouts, spacing, and styling. For example, using `container`, `row`, and `col` makes organizing a webpage much simpler. I also liked how Bootstrap includes components like navigation bars and buttons that you can easily customize.

During our ICS 314 WODs, I had fun recreating websites like Island Snow, Murphy's Bar and Grill, and HiCO Hawaiian Coffee. Each website had its own unique design, which made the assignments interesting and gave me a chance to be creative. At the same time, it was challenging trying to figure out which Bootstrap classes to use to make everything look similar to the original websites. Sometimes even a small spacing or alignment issue took a while to fix, but seeing the final result made it satisfying.

Although Bootstrap is useful, I think there are still advantages to using regular HTML and CSS. Writing your own CSS gives you more control over the appearance of your website, while Bootstrap requires you to learn its classes and how they work. However, I think UI frameworks are beneficial in software engineering because they save time, make websites more responsive, and help keep designs consistent, especially when working with other developers.

Overall, learning Bootstrap 5 has been a fun but challenging experience. I enjoyed seeing how different websites are structured and trying to recreate their designs myself. Even though I still struggle with remembering certain classes, I feel like I am slowly getting more comfortable using Bootstrap. This experience showed me that web development is not just about writing code, but also about being creative, experimenting, and solving problems along the way.
