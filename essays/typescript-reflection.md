So far, I think TypeScript has been pretty interesting to learn. I already knew some Java before this, so I was not completely new to programming. A lot of the ideas were familiar, like classes, methods, variables, and loops, but the syntax still felt different and kind of confusing at first. It reminded me of when I first learned Java because I struggled with the syntax in the beginning, but after using it more, I eventually got used to it.

One thing I learned more about was how TypeScript uses classes and objects, especially things like this, constructors, and different methods. I also got more practice with arrays and Maps and methods like get(), set(), and has(). At first, I had a hard time remembering which methods worked with which data types, but I feel like I understand that a lot better now. I used a decent amount of AI, mainly ChatGPT-5.6 Sol in order to help me to understand different methods.

I also learned some new ES6 stuff, especially the difference between var and let. Before this, I did not really think that much about variable scope, but now I understand why let is usually better in certain situations. Overall, I think TypeScript is a good language for software engineering because it gives you more structure than JavaScript and can help catch mistakes with types before the program even runs.

For athletic software engineering, I think the practice WODs are helpful, even though they can be stressful. The time limit makes me feel rushed sometimes, especially when I know what I want to do but cannot remember the exact syntax. At the same time, I think actually writing the code helps me learn way more than just reading about it.

Overall, I think this style of learning will probably work for me as long as I keep practicing. It can be stressful, but it also feels good when I finally get the code working. I had the same experience with Java, where it felt difficult at first but eventually became easier, so I think TypeScript will be the same way. Hopefully the other languages we will learn in this class will help strengthen my understanding of coding as a whole. It really forces me to stay on track with my assignments and learn more efficiently.
